## What this project does

This project helps builders create a clean, presentation-ready ID card in just a few steps. It combines a simple upload flow, live preview, and a polished export experience so the final card feels event-ready and professional.

### Key highlights
- Upload a JPG, PNG, or HEIC photo
- Adjust crop, zoom, and positioning with ease
- Add your name, role, and auto-generated builder title
- Preview the final card live before downloading it as a PNG
- Designed for quick sharing, printing, and event use

## How it works

1. Upload your photo
2. Fine-tune the image with crop and zoom controls
3. Enter your name, role, and builder title
4. Generate the final card and export it instantly

## Run locally

```bash
git clone https://github.com/aaryanbangale2306/Frame-Generator-HH-Goa.git
cd Frame-Generator-HH-Goa
py -m http.server 8000
```

Then open http://localhost:8000 in your browser.
