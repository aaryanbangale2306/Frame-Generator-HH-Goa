## ✨ What this project does

This project is a single-purpose builder ID card generator for HH Goa 2026. It focuses on a clean, premium experience with:

- a simple upload flow
- live crop and zoom controls
- a polished ID-card preview
- instant PNG download for sharing or printing

The experience is intentionally minimal so the final card stays the center of attention.

## 🚀 Key features

- Upload JPG, PNG, or HEIC photos
- Crop, zoom, and reposition your image with ease
- Generate a premium builder ID card directly in the browser
- Auto-generate builder-style titles based on your role
- Download the card as a PNG
- Share the final image with a built-in share flow

---

## 🛠️ Tech stack

- HTML5 for the layout structure
- CSS3 for styling, spacing, and responsive presentation
- Vanilla JavaScript for canvas rendering and UI interaction
- Canvas-based drawing for the final exported card
- HEIC conversion support via the heic2any library

## ▶️ Run locally

```bash

cd Frame-Generator-HH-Goa
npx http-server . -p 8080
```

Then open http://localhost:8080 in your browser.
